Mission details

Your data

What the project's server keeps about a player, what this site keeps, and how to have any of it deleted. Short, because there is little of it.

The policy

The server keeps what the game's own protocol requires and nothing else: the persona name, the password hash, the clan and the match statistics the game shows, and the clamped chat lines while a lobby is open. No analytics, no e-mail unless you gave one on the REPORT A BUG form, nothing sold or shared. Anything kept about you is deleted on request through the contact on this site.

What the server keeps

  • Your persona. The name you typed at the first login, and a hash of the password, never the password. The game creates the account itself on that first login.
  • Your clan and your statistics, if the game sends them: what the game shows on its own screens, and nothing it does not.
  • Chat, while a lobby is open. Lines are cut to length and passed on; they are not written down.
  • Backups. The account database on the server is backed up once a day, and old copies there are dropped as new ones arrive.

What is public

The SERVER section of the front page shows who is online and in which game, by persona name, with the game's name and map, and counts since the server started.

What this site keeps

A bug report, only when you send one, with the contact you typed if you typed one. An e-mail address, only if you left one under NOTIFY ME. The pages set no cookie and run no analytics; the live status is a poll of the server's own counter.

Resets and deletion

There is no password reset button, on the server or here. A password reset, or the deletion of everything kept about you, is done by hand on the server by the person who runs it. Ask through the REPORT A BUG form on the front page: put "password reset" or "delete my data" in the title and your persona name in the text, and a way to reach you if you want an answer.

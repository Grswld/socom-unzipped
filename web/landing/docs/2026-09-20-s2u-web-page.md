# s2u web page redesign (2026-09-20; live at /web.html since the same evening)

> Moved 2026-09-29 from scotho `docs/superpowers/specs/` into socom_pc `web/landing/docs/`, with the site. Paths are
> updated to the new layout; the history they describe is kept as it was. Today the web page is `index.html` at `/`
> (`/web.html` redirects there) and the console menu is `classic.html`; the story is generated by the landing build.

The owner asked for a full pass on a landing page: highly stylised, for SOCOM fans and agentic-engineering fans,
pleasant, polished, animated where it helps. It was built as index.html and, on the owner's instruction the same
evening, swapped: the console menu is the default view at `/` again and this page lives at `/web.html`, reached by
the WEB link under the speaker on the console (scotho-f2, 3b31e14). This is what it is and how it is put together.

## Pages

- `web/landing/index.html` (then `web.html`) + `src/home.ts` + `src/home.css`: the web page. A normal scrolling site in the
  game's palette and type: hero with the menu loop behind the logo and the menu items as a "wheel", What / How /
  Story / Server / Setup / Report sections, footer with the legal lines. Sound is off until the visitor turns it on
  (top-right), then the wheel and buttons use the game's menu sounds. Reduced motion turns every animation off and
  drops the video.
- `web/landing/classic.html` (then `index.html`) + `src/main.ts` + `src/style.css`: the original 640x480
  console-menu experience, then the default view. Its About screen has a DEVELOPMENT STORY button (77e9740) and a WEB link under the speaker. The web
  page's CLASSIC links point back at `/`.
- `web/landing/story.html`: the project's timeline, rendered by `tools_py/story/site.py`. Never edit it by hand, and
  never commit it (it is git-ignored): `web/landing/tools/prepare.mjs` generates it at build time with

      MSYS_NO_PATHCONV=1 python -m tools_py.story.site --full-document --out web/landing/story.html --img /story/img --logo /img/logo.webp

  and copies `docs/story/img/*` (pictures, and a video with its poster frame) and `docs/story/timeline.json` into
  `public/story/` (the procedure: `docs/story/UPDATING.md`). The `MSYS_NO_PATHCONV=1`
  matters under Git Bash: without it `/story/img` reaches Python as `C:/Program Files/Git/story/img`, which shipped
  once (9ce4458 is the repair) and cost the live page every picture. With it, `--out` must be a Windows path, since
  `/c/...` is no longer translated either. `site.py` now refuses an `--img` or `--logo` that carries a drive letter.

`vite.config.ts` registers the pages as rollup inputs (today main, classic, story, data and the gallery); `npm run build
-w landing` (in `web/`) emits them side by side.

## What the landing page reuses

- `src/stats.ts` for the server: the hero lamp polls `/api/stats` always; the SERVER section shows the same games and
  operatives as classic.
- `src/report.ts` for the bug form: same fields, checks and payload as classic and the launcher.
- `src/sfx.ts` for the sounds.
- `public/story/timeline.json` (copied from `docs/story/` at build time) for the "latest entries" strip; `src/home_data.ts` shapes it
  (pure, tested in `home_data.test.ts`).

## Numbers on the page

The HOW section (the five-step loop and the INTEL tiles) was removed on 2026-09-22, on the owner's word; the README's
one paragraph on how it was built stands under WHAT in its place, and the nav lost HOW. The numbers that remain are the
STATE section's (test counts from `docs/STATUS.md`, dated in the section's lede). Update them when the story
updates; they are plain HTML in index.html.

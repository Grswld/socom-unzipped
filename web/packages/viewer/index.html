    About dev build

    Not a port and not emulation. No game code runs. The disc's own data — geometry, textures, scene graph, lighting, fog — is read and drawn again in TypeScript, so it is a reading of the game and a reading can be wrong.

    Known to differ: blended surfaces are sorted by the browser where the engine traversed its grid outward from the camera, the frame brighten is a fixed value where the game meters it, the alternate states a map holds (destroyed, unlit, far LOD) are hidden rather than switched by play, and there is no game — just the world.

    A spin-off of SOCOM Unzipped, the actual port. socomunzipped.com →

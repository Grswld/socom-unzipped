# Sprint 16 Implementation Plan — "ten minutes to the server" (OPEN 2026-09-27 07:00Z; proposed 06:14Z)

> Spec: `docs/superpowers/specs/2026-09-27-sprint-16-ten-minutes-to-the-server-design.md` (scoped with the owner on the
> evening of 2026-09-26/27, validated against the research corpus). Written 2026-09-27 by the Sprint 16 controller
> while Sprint 15 is open, against the tree at sprint-15's tip `6f57eb1e` and six read-only readers' findings;
> **opens when Sprint 15's Task 99 closes** (the tag `v0.15.0` on `main`) — branch `sprint-16` off `main` at that
> merge. Until the open, the owner's word of 2026-09-27 05:57Z lets lock-free tasks start on topic branches off
> `main` (D15 below); the table says which did. The loop runs this plan with the `loop-iteration` skill: one task at a
> time, a failing test first, review by a fresh agent, the lock for every build and run, the merged chain as the gate
> unit, every lock-bound step a window (R297).

**Goal:** a first-time player picks r0004 in the launcher and is playing on the community server ten minutes later,
from a download that carries no game bytes, at a frame rate the gate refuses to let slip: the launcher builds the ELF
from the player's own ISO (#70) and fetches, decrypts and merges the r0004 package (#71); the player archive ships
without the ELF, the debugger or the probes (R290, R295); the mission frame's time is measured, its largest cost
attacked once, and #59's ceiling written as a refusal; the launcher's ONLINE page shows the personas (#73) and the
CONTROLLER page explains its controls (#74). Nothing here changes the acceptance bar of 2026-09-09.

**Architecture:** four milestones — **R** the exe-only release (a spike decides the decrypt's route, then one
implementation the launcher uses; the packaging split beside it; the r0004 package on the same decrypt), **F** the
frame rate (measure first, then the GL thread's top phase, the `-O2` A/B, the conditional levers, the fence), **L**
the launcher's face (a design note, then the build; the tooltips), **X** fillers. Each task in an agent worktree or,
lock-free, a cloud session (D14); every lock-bound step a window; the merged chain proves each batch; KNOWN moved
with the evidence. The Sprint 15 legs the owner deferred run as this plan's first chain (V0).

**Tech Stack:** C++17 (llvm-mingw, `build.sh`; clang on Linux, `scripts/build_linux.sh`), Python 3 unittest,
`ps2xTest` (MiniTest), `tools_py/parity/gate.py` and `pins.py`, `frame_time.py`, `audio_parity.py`, `audio_dips.py`,
`window_drag.py`, the host sampler (`PS2X_HOST_PROF*`) with `hostprof_symbolize.py` / `hostprof_stacks.py`, the GS
trace (`PS2X_GS_STATS`, `PS2X_GS_UPLOAD_TRACE`), the project's recompiler (`ps2_recomp`), Unicorn (the Python decrypt
being replaced), `scripts/loop_lock.sh`, `scripts/run_detached.sh`, `scripts/parity/merged_chain.sh`,
`scripts/agent_worktree.sh`, `gh`, the remote-trigger routines for cloud sessions.

## Review Focus

The five input classes the spec implies and no bar exercises, each pinned to a task's test below, most likely first:

1. **A disc that is not the r0001 US image** (another region or revision, a scrubbed or truncated ISO): the first-run
   decrypt refuses with one sentence and writes no ELF — R1b's test: a fixture image whose file digests differ from
   `tools_py/disc_to_elf_expected.json` is refused before any write.
2. **A first run interrupted mid-decrypt** (the launcher closed, the machine slept): a partial ELF must never read as
   built — R1b writes to a temporary name and renames only after the digest verifies; its test plants a partial file
   beside the exe and expects the DISC step to start over, not exit 68's "built".
3. **The r0004 fetch fails or lies** (unreachable host, a 404, a truncated body, a wrong-size or wrong-digest file):
   the GAME VERSION toggle stays on r0001 with a sentence and nothing is merged — R2's fixture server serves each case.
4. **A card folder whose ledger is missing, empty, corrupt, or names a persona with every character the OSK allows**
   (R201): the viewer shows what it can and never crashes or launches with a name it did not read — L1b's fixtures.
5. **A gate on a slower or faster host than this one** (a contributor's machine): the frame ceiling is this host's
   number; on another harness the line stays informational and says so, never a refusal — F5's test with a differing
   harness block.

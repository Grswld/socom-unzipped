**Goal:** the gate's mission scene runs at sixty guest frames a second with parity at 1x (`FRAME mean=` ≤ 17.0 ms,
`worst1s=` ≤ 20.0 ms, `syncv/s` within 5 % of the VBlank rate, three quiet gates, no moved pixel), or the sprint
records the number reached and the ranked residual; leaving SOCOM Online or a mission's briefing lands on the main
menu instead of exiting the process; the online lobby has its first audio recording on both sides; the online
menus' test harness is scoped.

**Architecture:** four milestones in the owner's order. **F** the frame rate: three missing instruments first (a
per-frame histogram, the game's own frame rate in the gate, a player-condition run), then the replay thread's costs
one measured attempt at a time (the draw path's CPU work, the read-backs, the loop's remainder), a structural pacing
change only if the guest still waits, 3x scale stamped and its rate recorded, the fence re-cut. **Q** the way back: a
spike that reads the argv and the failing kernel search, the kernel-patch prologue made to complete, `LoadExecPS2` as
an in-process restart, the announcement scroller checked against the console. **A** the lobby's sound: the owner's
listen gates the stutter work; the lobby recording runs regardless. **H** the harness, scoped in a note. Each task in
an agent worktree; the merged chain proves each batch; KNOWN moved with the evidence.

**Tech Stack:** C++17 (llvm-mingw, `build.sh`), Python 3 unittest, `ps2xTest` (MiniTest), `tools_py/parity/gate.py`,
`pins.py`, `frame_time.py`, `drive.py`, `window_drag.py`, `audio_parity.py`, `audio_dips.py`,
`mission_music_long.sh`, `audio_parity.sh`, `pcsx2_shell.py`, the GS trace (`PS2X_GS_STATS`, `PS2X_GS_UPLOAD_TRACE`,
the `[gs-submit]` line from Sprint 16 F2), the call trace (`PS2X_CALL_TRACE`, `PS2X_CALL_TRACE_DUMP`), `PS2X_PEEK`,
`PS2X_SCHED_TRACE`, the host sampler, the local Horizon stack (`server/`), `scripts/loop_lock.sh`,
`scripts/run_detached.sh`, `scripts/parity/merged_chain.sh`, `scripts/agent_worktree.sh`, `gh`.

  `docs/LATER.md` with the measured reason; a task out of order needs a ruling.
- **Windows (R297):** every build, game run or chain is announced as a window by the session that runs it; game runs
  wait for a window the owner names (O20); nothing heavy under 3 GB free (`scripts/run_detached.sh` refuses); `-j 4`
  while another session builds; one suite at a time, never under a build.
- **Merges (R294):** agent code a Fable-class reviewer passed with high confidence, or that tests confirm, merges to
  `main` without a human review until the owner calls stability; every task gets a fresh reviewer; findings
  `file:line`; fix rounds to a clean re-review.
- **A failing test first**, unittest only (Python) or a `ps2xTest` case (C++); RED and GREEN pasted into the Log; a
  performance change's measurement named with today's value before its branch exists; a stop rule per trial; TRIED,
  NOT ADOPTED is a recorded outcome; nothing accepted from a failed run; **a change that moves a pixel or a score is
  not adopted** (the gate 3/3 PINS MATCH, `--vram-diff` 15/15, the console-replay case, the fourth leg).

  `scripts/check_quiet_gate.sh` and `scripts/kill_stale_drivers.ps1` before a launch; a chain script is copied under
  `logs/` before it runs and never edited while it runs; a gate and a plain run never overlap.
- **Nothing derived from the disc enters the tree** (not a byte of `game/`, `recomp/output*/`, `logs/`, a recording,
  a served package, a card); a count from the generated code is cited with its command.
- **Nothing that is the owner's is performed:** no publish, no change to the hosted server's configuration or the
  site (Q3 uses the **local** Horizon stack), no connection to a server that is not ours, no upstream filing (O10).
- **KNOWN wins;** a finding that moves a row moves it in KNOWN with its artefact, in the commit that carries the
  evidence; the two ruled-out rows spec §1.8 names are rewritten in Task 0, none retired without a citation.
- **Commit with an explicit pathspec;** the leak check in the hooks; never `--no-verify`; subjects under 120
  characters; a linked worktree never pushes (the main tree does, after review).
- **The chain's tree is nobody else's (Sprint 16's lesson 1):** the merged chain never shares a working tree with a
  committing session -- five of Sprint 16's runs went red on the main tree's HEAD moving under the owner's own docs and web
  commits, 90 minutes each. G1 lands the guard before the first chain; until it does, the chain's build and suite steps

  to write, never written by the peer; this plan's ceiling is 59,100 bytes (`tools_py/docmaint.py`).
- **Before every fast-forward (lesson 5):** merge the main tree's `sprint-17` into the controller branch first -- the
  owner's sessions commit there, and origin can run ahead of the main tree through PRs merged on GitHub.

- **Attempts are knobs on one exe (R334):** an F attempt lands behind a Dev knob defaulting to the old behaviour,
  merges on its review and module tests, and is measured on the day's exe by flipping one knob per run; adoption
  flips the default; replaces F1's "one build and one gate each" (DEVELOPING "Measuring a change without a chain").

## Review Focus

Five inputs the spec implies and no bar names; each has its test in the task that owns the code.

1. **A present interval longer than the last histogram edge** (a window drag, a 2 s back-pressure timeout): it lands in
   the open-ended last bucket and in `longest`, never wraps or is dropped — F0 (a)'s case.
2. **A gate summary from another host, or without the `syncv` line** (an older exe, a Linux run): F6's ceiling reports
   "not compared" with the reason and does not refuse — F6's second case.
3. **`LoadExecPS2` with `argc=0`** (a plain reboot, the console's other use): Q2 restarts with no arguments and the
   crt0 reads `argc=0`, no fault — Q2's third case.
4. **F2's deferred read-back handing the guest a pixel from before the target was redrawn:** the mapped bytes equal
   the synchronous path's for a target drawn, read, redrawn, read — F2's second case.
5. **A 1,000-character announcement body with newlines and a trailing space:** the local server writes it whole at
   `ANNOUNCEMENT_MAXLEN` and the drive does not press through the page while it scrolls — Q3's dry-run check.
